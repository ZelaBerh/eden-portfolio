# Eden Abeselom Habteslasie | Data analyst portfolio

A static portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Run `python3 -m http.server 8000` in the repository root and open http://localhost:8000. The chart's contract filter loads its data over HTTP.

## Deploy to Vercel

Import this GitHub repository into Vercel. Keep the repository root as the project root and use the Other framework preset. The checked-in Vercel configuration serves the files directly. No dependencies, environment variables, or build step are required.

## Project evidence

Project files are in [Eden’s Data Analysis Portfolio](https://github.com/Edenabeselom/Data-Analysis-Portfolio). The WDI image is Eden’s original dashboard screenshot, embedded as WebP in a standalone SVG image. The churn chart uses aggregate counts from the published Telco Customer Churn CSV. For each contract and internet service combination, churn rate is the count of records with `Churn=Yes` divided by the number of records in that segment.
